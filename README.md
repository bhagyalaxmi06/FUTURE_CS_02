# FUTURE_CS_02

Task 2 – Phishing Email Detection & Awareness System

This project demonstrates phishing email analysis by examining sender domains, suspicious links, email content, and security indicators. The project classifies emails into Safe, Suspicious, and Phishing categories and provides recommendations to improve cybersecurity awareness and reduce phishing risks.

Phishing Email Detection &amp; Awareness System developed as part of the Future Interns Cyber Security Internship (Task 2). This project focuses on identifying phishing indicators, classifying emails as Safe, Suspicious, or Phishing, analyzing associated risks, and providing cybersecurity awareness and prevention guidelines.
